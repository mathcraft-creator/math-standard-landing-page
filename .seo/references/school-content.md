# 학교별 콘텐츠 작성 기준

- 작성일: 2026-09-21 (KST)
- 첫 적용 대상: 풍양중 수학
- 관련 원칙: [지역·학교 SEO 운영 원칙](./local-seo.md)

## 1. 학교 허브의 역할

학교 허브는 특정 학교명을 검색한 학생과 학부모에게 다음 질문을 한 페이지에서 답하는 상시 안내 문서다.

- 이 학원이 해당 학교 시험을 어떤 자료와 기준으로 분석하는가?
- 현재 공개할 수 있는 실제 시험 정보는 무엇인가?
- 학년별로 어떤 준비가 필요한가?
- 수업과 상담을 더 알아보려면 어디로 이동해야 하는가?

대표 URL에는 연도를 넣지 않는다. 허브는 확인된 최신 시험 자료를 요약하고, 자료가 충분한 시험별 분석 문서로 연결한다. 원자료가 없는 상태에서는 시험 수치나 경향을 채운 얇은 허브를 공개하지 않는다.

## 2. 권장 정보 구조

1. **Hero:** 학교명과 페이지 목적을 분명히 설명한다.
2. **짧은 답변:** 2~4문장으로 분석 방식과 준비 순서를 바로 답한다.
3. **현재 확인된 범위:** 어떤 학년·학기·시험 자료를 근거로 하는지 밝힌다.
4. **시험 분석 요약:** 문항 구성, 단원, 유형 등 실제 자료에서 확인한 사실을 보여준다.
5. **학년별 안내:** 해당 학년의 검증된 자료가 있을 때만 중1·중2·중3 섹션을 연다.
6. **대비 방식:** 학교별 시험 분석, 서술형 연습, 오답 재풀이, 재테스트 등 현재 중·고등 과정에서 확인되는 학습 방식을 설명한다.
7. **시험별 문서:** 실제 자료가 충분할 때만 하위 분석 문서로 연결한다.
8. **FAQ:** 페이지 본문으로 답할 수 있고 실제 상담 의도와 연결되는 질문만 싣는다.
9. **출처·방법:** 원자료 기준일, 분석일, 사실·계산·해석의 구분을 설명한다.
10. **상담 CTA:** 중·고등 과정과 상담 신청으로 연결한다.

자료가 없는 섹션은 `준비 중` 문구로 채우지 말고 페이지에서 제외한다. 비어 있는 표, 예시 수치, 가상의 후기 역시 사용하지 않는다.

## 3. 제목과 첫 답변 작성법

H1에는 학교명과 사용자의 핵심 과제를 한 번 자연스럽게 쓴다. 파일럿 권장 후보는 `풍양중 수학, 실제 시험을 분석해 준비합니다`이며, 원자료 확보 전에는 운영 페이지에 게시하지 않는다.

첫 답변은 다음 순서를 따른다.

1. 실제 시험지에서 무엇을 확인하는지 설명한다.
2. 확인된 취약 단원과 유형을 수업에 어떻게 반영하는지 설명한다.
3. 페이지에는 실제 자료로 확인된 내용만 공개한다고 밝힌다.

제목과 첫 문단에 `풍양중 수학`, `풍양중 수학학원`, `풍양중 내신`을 모두 나열하지 않는다. 검색어 변형은 본문 내용이 필요할 때 자연스럽게 사용한다.

## 4. 시험 데이터 최소 요건

시험별 분석을 공개하려면 최소한 다음 값이 필요하다.

| 구분 | 필수 데이터 |
| --- | --- |
| 식별 | 학교명, 학년도, 학년, 학기, 시험 종류 |
| 출처 | 원자료 식별자 또는 경로, 자료 유형, 입수·검수 상태 |
| 문항 | 전체 문항 수, 문항별 번호, 객관식·서술형 구분 |
| 범위 | 단원 또는 시험 범위와 그 근거 |
| 분석 | 문항 유형, 난이도 기준, 분석 방법, 분석일 |
| 공개 | 원문·이미지 게시 권한, 개인정보 제거 확인 |

배점이 원자료에 없으면 임의로 보완하지 않는다. OCR 결과는 초안 데이터로 취급하고 사람이 시험지와 대조한 뒤에만 수치 계산에 사용한다.

## 5. 학년별·추세 콘텐츠 규칙

- 중1·중2·중3을 모두 기본 목차로 만들지 않는다. 해당 학년의 실제 자료가 있는 섹션만 공개한다.
- 시험 한 건으로 `최근 출제 경향`, `서술형 증가`, `난이도 상승`을 주장하지 않는다.
- 추세는 같은 학교와 비교 가능한 조건의 시험이 두 건 이상 있을 때만 다룬다. 비교 기준과 표본 수를 함께 표시한다.
- 교육과정이나 시험 범위가 바뀌면 직접 비교 가능 여부를 먼저 판단한다.
- 특정 학생의 성적 변화는 동의와 검증 없이 사례로 사용하지 않는다.

## 6. 출처 표시 형식

공개 페이지의 분석 블록에는 다음 형식을 권장한다.

- **자료 기준:** 예: `2026학년도 중2 1학기 기말 수학 시험지`
- **분석일:** 실제 분석 완료일
- **관찰 사실:** 원자료에서 직접 확인한 항목
- **계산 데이터:** 산식과 분모가 있는 집계
- **학원 분석:** 난이도 기준과 준비 제안

내부 데이터에는 원자료 식별자, 검수자, 검수일도 남긴다. 공개 페이지에는 개인정보나 권한이 확인되지 않은 원문을 노출하지 않는다.

## 7. 구조화 데이터 기준

- 페이지 본체에는 `WebPage`를 사용한다.
- 경로 탐색이 실제 화면에 있으면 `BreadcrumbList`를 사용한다.
- 화면에 보이는 FAQ 질문과 답변이 구조화 데이터와 정확히 같을 때만 `FAQPage`를 추가한다.
- 학원 정보는 기존 공통 엔터티 `/#academy`와 중·고등 브랜드 `/#secondary-academy`를 참조한다.
- 학교를 학원 소유 조직이나 지점으로 표현하지 않는다.
- 시험별 하위 문서가 실제 분석 보고서 역할을 할 때 `Article`을 검토한다. 작성자, 게시일, 수정일은 실제 값만 쓴다.
- 검색결과의 확장 노출을 보장하는 표현은 하지 않는다.

## 8. 내부 링크와 CTA

홈과 중·고등 과정 페이지에서 학교 허브로 연결할 때는 사용자가 이동 후 볼 내용을 설명하는 앵커를 쓴다. 학교 허브에서는 중·고등 과정 설명과 상담 신청으로 되돌아갈 수 있어야 한다.

CTA는 시험 분석보다 앞서 반복하지 않는다. 권장 순서는 핵심 답변, 실제 분석, 대비 방식, 과정 안내 또는 상담이다. 상담 문구는 `풍양중 공식`, `학교 지정`, `적중 보장` 같은 표현을 사용하지 않는다.

## 9. 갱신 정책

- 허브의 `lastmod`와 화면 수정일은 내용이 실질적으로 바뀐 날에만 갱신한다.
- 새 시험 자료를 추가할 때 이전 분석을 조용히 덮어쓰지 않는다. 시험별 기준일을 유지하고 필요하면 하위 문서를 추가한다.
- 오탈자와 사실 오류를 정정하면 내부 작업 기록에 이유를 남긴다.
- 원자료가 철회되거나 공개 권한이 사라지면 관련 이미지와 상세 수치를 재검토한다.
- 최소 분기 1회, 그리고 새 시험 분석 후에 내부 링크, 출처, NAP, 구조화 데이터를 점검한다.

## 10. 확장 조건

풍양중 파일럿에서 다음 항목을 확인한 뒤 다른 학교로 확장한다.

- 실제 자료를 수집하고 검수하는 과정이 반복 가능하다.
- 페이지가 유효한 검색 노출과 사용자의 정보 탐색을 만든다.
- 상담 CTA가 본문 신뢰를 해치지 않는다.
- 다른 학교에 그대로 복사하지 않고 학교별 고유 정보로 작성할 수 있다.
- 운영자가 학기마다 자료와 정정 이력을 관리할 수 있다.
