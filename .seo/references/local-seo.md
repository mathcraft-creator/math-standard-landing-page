# 지역·학교 SEO 운영 원칙

- 작성일: 2026-09-21 (KST)
- 적용 범위: `math-standard-landing-page`의 지역·학교 관련 공개 페이지
- 목적: 검색어를 반복하는 얇은 페이지가 아니라, 실제 자료와 분명한 사용자 의도를 갖춘 페이지를 일관되게 만든다.

## 1. 기본 원칙

1. 페이지 하나는 하나의 대표 검색 의도와 대표 URL을 가진다. 유사 검색어마다 별도 페이지를 만들지 않는다.
2. 지역명·학교명은 문맥상 필요한 제목, 본문, 탐색 링크에만 쓴다. 제목과 문단에 기계적으로 반복하지 않는다.
3. 학교와 학원의 공식 제휴, 지정 학원, 학교 공식 자료라는 인상을 주는 표현을 사용하지 않는다.
4. 시험 분석은 실제 시험지 또는 출처가 확인되는 자료를 확보한 뒤 공개한다. 문항 수, 배점, 단원 비중, 난이도, 출제 경향을 추정해서 채우지 않는다.
5. 학교 허브는 오래 유지되는 안내 페이지로 운영하고, 특정 연도·학기·시험 분석은 출처가 갖춰졌을 때 하위 문서로 분리한다.
6. 같은 의도의 페이지가 여러 개 생기면 합치고 대표 URL로 내부 링크와 canonical을 통일한다.
7. 정보가 부족한 학교 페이지를 대량 생성하지 않는다. `풍양중 수학` 파일럿을 검증한 뒤 다음 학교로 확장한다.

## 2. URL과 페이지 역할

학교 허브 권장 형식은 `/schools/<school-slug>/`이다. 풍양중 파일럿의 대표 URL은 `/schools/pungyang-middle/`로 정한다. 이 URL에는 연도를 넣지 않아 매년 같은 학교 허브로 유지한다.

실제 시험 자료가 있고 허브와 구별되는 검색 의도를 충족할 때만 시험별 하위 문서를 만든다. 예시는 `/schools/pungyang-middle/exams/2026-grade-2-first-semester-final/`이다. 최종 슬러그는 원자료의 학년·학기·시험 구분을 확인한 뒤 확정한다.

다음 조건을 모두 충족해야 새 학교 또는 시험 페이지를 공개할 수 있다.

- 대표 검색 의도가 기존 페이지와 구별된다.
- 원자료와 분석 근거가 있다.
- 페이지에 표시할 사실이 구조화 데이터와 일치한다.
- 내부 링크, canonical, sitemap 반영 계획이 있다.
- 독립적으로 읽을 만한 정보량이 있고 단순 키워드 치환 페이지가 아니다.

## 3. NAP 일관성

공개 페이지와 구조화 데이터에서는 다음 정보를 기준값으로 사용한다.

| 항목 | 기준값 |
| --- | --- |
| 상호 | 딱풀리는수학 진접점 · 수학의 기준 진접본원 |
| 주소 | 남양주시 진접읍 해밀예당1로 40 화성프라자 5층 |

띄어쓰기, 지점명, 전화번호가 페이지마다 달라지지 않게 한다. 학교 페이지가 특정 학교의 공식 사이트처럼 보이지 않도록 학원 상호와 연락처의 주체를 명확히 표시한다.

## 4. 사실과 해석의 구분

시험 분석에서는 정보를 다음 세 종류로 표시하거나 문맥상 명확히 구분한다.

- **관찰 사실(Observed Fact):** 시험지에서 직접 확인한 학년, 학기, 시험명, 문항 수, 객관식·서술형 구분, 배점, 단원.
- **계산 데이터(Calculated Data):** 관찰 사실을 기준으로 계산한 단원별 문항 비율, 배점 비율, 유형 분포. 계산식과 분모를 기록한다.
- **학원 분석(Academy Analysis):** 난이도 판단, 준비 우선순위, 오답 원인에 대한 해석. 판단 기준과 분석일을 함께 기록한다.

난이도와 경향은 관찰 사실처럼 표현하지 않는다. 서로 비교할 수 있는 실제 시험이 두 건 이상 없으면 상승·하락·증가·감소 같은 추세 표현을 쓰지 않는다.

## 5. 콘텐츠와 상담 CTA 균형

페이지의 첫 화면과 본문은 사용자가 찾는 학교·시험 정보를 먼저 답한다. 상담 CTA는 분석 내용을 가리지 않도록 소개 뒤와 페이지 하단에 제한적으로 둔다. CTA 문구는 학습 상담의 주체가 학원임을 밝히며 학교의 공식 권고나 보증처럼 표현하지 않는다.

권장 내부 링크 문구는 문맥에 맞게 다양화한다.

- 중·고등 과정 안내: `수학의 기준 중·고등 수업 방식`
- 학교 허브: `풍양중 수학 시험·내신 정보`
- 시험 분석: `2026학년도 중2 1학기 기말 분석`
- 허브로 돌아가기: `풍양중 수학 시험 정보`

정확히 같은 키워드 앵커를 여러 위치에 반복하지 않는다.

## 6. canonical, 색인, 변경 관리

- 공개 페이지는 자기 자신을 가리키는 절대 URL canonical을 둔다.
- 추적 파라미터나 중복 경로는 canonical 대상이 아니다.
- 초안, 데이터가 없는 템플릿, 내부 검수용 페이지는 배포하거나 sitemap에 넣지 않는다.
- 공개 승인 후에만 sitemap과 `llms.txt`를 갱신한다.
- 원자료 수정이나 분석 정정 시 수정일과 변경 이유를 기록한다. 시험지에서 확인한 사실과 학원 해석을 함께 바꾸지 않는다.
- 페이지 제거가 필요하면 관련 내부 링크와 sitemap을 먼저 정리하고 적절한 HTTP 상태 또는 대체 URL을 결정한다.

## 7. 출처와 개인정보

원자료의 파일명 또는 내부 식별자, 시험 정보, 입수 경로, 분석일, 검수자를 내부 기록에 남긴다. 시험지 이미지나 문항 원문을 공개할 때는 저작권과 게시 권한을 확인하고 학생 이름, 학번, 필기 등 개인정보를 삭제한다. 권한이 불분명하면 원문 이미지를 공개하지 않고 검증된 집계값과 분석 방법만 제공한다.

## 8. 공개 전 품질 게이트

- 원자료가 실제로 존재하고 사람이 대조 검수했다.
- 학교명, 학년, 연도, 학기, 시험 구분이 확인됐다.
- 수치가 원자료 또는 명시된 계산식과 일치한다.
- 난이도 기준과 분석일이 기록됐다.
- 제목, H1, 소개문, 본문이 같은 검색 의도를 다룬다.
- 학교와의 공식 관계를 암시하는 문구가 없다.
- 모바일에서 핵심 답변과 표를 읽을 수 있다.
- canonical, 구조화 데이터, 내부 링크가 실제 공개 URL과 일치한다.
- HTTP 200, 색인 허용, sitemap 반영을 확인했다.
- 공개 후 Search Console과 네이버 서치어드바이저에서 수집·색인 상태를 추적할 수 있다.
