01 · 관리형 플립러닝

설명을 듣는 시간과
직접 푸는 시간을 연결합니다.

집에서는 자신의 속도로 개념을 준비하고, 학원에서는 선생님과 풀이의 막힌 지점을 확인합니다.

BEFORE CLASS · 집에서

원장 개념 영상으로 준비

필요한 개념을 미리 접하고, 어려운 부분은 반복해서 확인합니다.

  • 원장 직강 개념 영상
  • 학생별 영상 시청 여부·시간·진도 확인
  • 질문할 부분을 준비하는 학습 루틴
IN CLASS · 학원에서

문제풀이와 피드백에 집중

숙제와 문제풀이를 학원에서 진행하며, 필요한 순간에 질문하고 첨삭받습니다.

  • 혼자 문제를 푸는 시간 확보
  • 학생 옆에서 풀이과정 확인
  • 개별 질문·오답 첨삭·재테스트

배운 개념이
내 풀이가 되는 다섯 단계.

  1. 개념 준비

    개념 영상을 미리 보고 필요한 부분을 반복합니다.

  2. 직접 풀이

    학원에서 문제를 풀며 적용 능력을 확인합니다.

  3. 질문·첨삭

    막힌 지점을 찾고 풀이과정을 다듬습니다.

  4. 오답클리닉

    틀린 원인을 분류하고 필요한 학습을 보완합니다.

  5. 재테스트

    혼자 다시 해결할 수 있는지 확인합니다.

02 · 오답을 끝내는 기준

“다시 풀면
맞힐 수 있니?”

오답노트를 작성한 사실보다, 같은 개념을 다시 꺼내 쓸 수 있는지를 확인합니다.

원인 분류 → 개념 보완 → 직접 재풀이 → 재테스트

메타인지 오답노트

문제 읽기, 개념, 적용, 계산, 풀이 순서 중 틀린 원인을 구분합니다. “실수했어요”에서 한 걸음 더 들어가 무엇을 바꿀지 찾습니다.

구하는 것 → 단서 → 연결할 개념

MCS 사고력 학습법으로 문제의 목표(Mission), 핵심 조건(Clue), 적용할 개념(Schema)을 정리합니다. 계산하기 전에 접근 순서를 생각합니다.

주간 테스트와 오답클리닉

보완한 문제를 직접 다시 풀고, 주간 테스트와 재테스트로 확인합니다. 학생별 진도·오답 유형·결과를 다음 수업에 반영합니다.

03 · 학교별 시험 준비

우리 학교 시험을 살피고,
필요한 유형을 반복합니다.

학교별 시험 범위와 자료를 분석하고 자체 교재 ‘시성비’로 교과서부터 변형·서술형까지 연결합니다.

MIDDLE SCHOOL

중등 · 기본에서 서술형까지

풍양중 · 주곡중
  • 교과서와 핵심 개념 확인
  • 교과서 변형 기본·발전 문제
  • 서술형 풀이와 심화 유형
  • 단원별 테스트와 반복 확인
HIGH SCHOOL

고등 · 적용에서 실전까지

진접고 · 광동고 · 오남고
  • 교과서·학교 자료 기반 준비
  • 변형 유형과 모의고사 문제 연결
  • 조건 해석·서술형 감점 점검
  • 시간 제한 풀이와 실전 테스트

시험 전 4주부터,
시험이 끝난 다음까지.

틀린 문제의 원인을 다음 학습으로 연결하는 과정까지가 시험 대비입니다.

  1. 4주 전

    범위와 학교 자료를 확인하고, 진단으로 부족한 개념을 보완합니다.

  2. 3주 전

    시성비로 대표 유형과 서술형을 익히고 단원별로 점검합니다.

  3. 2주 전

    변형·고난도 문제와 시간 제한 풀이로 적용 능력을 확인합니다.

  4. 1주 전

    실전 테스트, 오답 재풀이, 서술형 감점 점검에 집중합니다.

  5. 시험 후

    문항별 오답을 분석하고 다음 시험의 학습 방향을 다시 설계합니다.

바꾼 학습 개념 학습과 시험 대비를 나누고, 영상·질문·오답·반복 테스트를 연결했습니다.
변화의 방향 진도를 끝내는 것에서 실제로 적용할 수 있는지를 확인하는 공부로 바뀌었습니다.

바꾼 학습 메타인지 오답노트로 원인을 나누고, 일주일 뒤 오답클리닉 테스트로 확인했습니다.
변화의 방향 자신의 실수 패턴을 알고, 무엇을 고쳐야 하는지 이해하기 시작했습니다.

바꾼 학습 오답을 되짚고 풀이를 확인하는 과정을 이어갔습니다.

학원의 실제 지도 기록을 바탕으로 학습 과정을 요약했습니다. 학생별 출발점과 변화는 다릅니다.

QUESTIONS & ANSWERS

처음 만나는 플립러닝,
궁금한 점을 확인하세요.

영상으로만 배우는 수업인가요?

아닙니다. 개념 영상은 수업을 준비하고 복습하는 도구입니다. 핵심은 학원에서 진행하는 직접 문제풀이, 개별 질문, 첨삭, 오답관리와 재테스트입니다.

영상을 못 보고 오면 어떻게 하나요?

학원 태블릿으로 필요한 개념 영상을 보완한 뒤 문제풀이와 질의응답을 진행합니다. 영상 시청 시간이 수업에 포함되므로 문제풀이와 첨삭 시간이 줄어들 수 있어, 미리 보는 루틴을 함께 만들어갑니다.

아이가 질문을 잘 못해도 괜찮나요?

학생의 풀이과정을 직접 보며 어디에서 막혔는지 먼저 확인합니다. 어느 부분까지 혼자 풀 수 있었는지 질문하며, 필요한 도움을 요청하는 습관을 기르도록 돕습니다.

오답은 어떻게 확인하나요?

틀린 원인을 개념, 조건 해석, 적용, 계산, 풀이 순서 등으로 나눕니다. 필요한 부분을 보완하고 직접 다시 푼 뒤 주간 테스트와 오답클리닉 재테스트로 확인합니다.

학교별 시험 대비도 하나요?

풍양중·주곡중과 진접고·광동고·오남고 등 학교별 시험 범위와 유형을 분석합니다. 자체 교재 시성비, 서술형 풀이, 테스트·재테스트를 활용해 대비합니다.

바로 등록해야 하나요?

먼저 진단과 상담으로 아이의 상태와 필요한 공부를 확인합니다. 1주일 체험으로 수업 방향이 맞는지 살펴본 뒤 결정하셔도 괜찮습니다. 신규 상담은 중1~고1을 중심으로 하며, 학년별 일정과 수강료는 상담에서 안내드립니다.
