# 학교별 6학기 과목 선택 설계 구현·검증

작업일: 2026-11-23. 기능 브랜치 `feature/curriculum-explorer`의 기존 미커밋 탐색관 통합 작업을 보존하며 추가 구현했다. 이 문서는 로컬 결과다. Production 배포·커밋·push를 하지 않는다.

## 구현한 범위

`/curriculum/planner/`에 독립 정적 HTML/CSS/JavaScript 페이지를 추가했다. 학교·2027 입학연도·시작 학기·목표 학과/진로·추천 방식을 입력하면 학기별 학교지정 과목과 선택군의 조합을 보여 준다. 후보를 선택하지 않은 자유 입력은 목표로 확정하지 않는다. 전공 미정 선택도 가능하다.

- 진접고·오남고·진건고: 해당 코호트 6학기 편성 자료.
- 광동고: 사용자 제공 네이버 캡처 4개 학기의 60개 표시 행 조회 및 목표 학과 관련성 표시. 캡처의 학점·선택군·입학/적용연도가 미표기라 2027 입학생 완성 추천은 비활성화. 다른 입학연도로 대신하지 않음.
- 학과 119개와 진로 별칭의 후보 검색. 진로 별칭은 학과 선택을 돕는 해석이며 대학 공식 판정이 아니다.
- 추천 조합 최대 3개, 선택군별 이유·원문/엑셀 셀·과목 설명·대안.
- 학과 관련 과목의 포함/미포함/해당 학교 자료에 없음 구분.
- 과목 고정·제외, 자동 재계산 또는 추천 버튼으로 재계산. 초과 선택·고정/제외 충돌은 오류로 알림.
- 시작 학기 이전의 선택 기록은 입력하지 않으면 그대로 미확인. 과거 과목을 추천으로 채우지 않으며, 이수 확인과 편성상 지정 과목을 구별함.
- 입력 저장/복원(이 브라우저), 자료 버전 변경 및 손상 저장값 거부. 결과는 저장하지 않고 복원 시 다시 계산함.
- 문장 복사·권한 차단 시 직접 복사 텍스트·인쇄/PDF 레이아웃.
- 학교 조회 실패 시 이전 학교 자료를 지우고 추천을 비활성화해 학교 선택과 결과가 뒤섞이지 않게 함.

계정·백엔드·AI API·개인정보 입력·자동 학교 수강신청·자동 상담 전송은 추가하지 않았다.

## 데이터 검수

`scripts/import-school-curricula.py`가 원본 엑셀을 읽고 `data/curriculum/`에 파생 JSON을 생성한다. 기존 탐색관 JSON에서 과목/학과의 최소 색인을 생성하지만 원본 JSON은 변경하지 않는다. 원본 엑셀을 저장하거나 수정하지 않는다.

| 학교 | 원본 2027입학생_3개년 행 | 선택군 | 교과 학점(6학기) |
|---|---:|---:|---|
| 진접고 | 122 | 18 | 30 / 29 / 30 / 29 / 30 / 29 |
| 오남고 | 111 | 14 | 29 / 29 / 29 / 29 / 29 / 29 |
| 진건고 | 112 | 14 | 29 / 29 / 29 / 29 / 29 / 29 |
| 광동고 | 실제 과목 0 | 0 | 자료 미확보 |

총 345개 편성 행은 선택 후보를 포함한다. 실제 학생 수강 개수나 고유 과목 개수가 아니다. 다음을 변환 시 검증한다.

1. 입학연도 2027, 적용연도 = 입학연도 + 학년 - 1.
2. 원본 과목·학점·선택군·선택 조건·출처 셀/URL·확인 상태 보존.
3. 택N의 숫자 및 ‘후보 K과목’의 K와 실제 후보 수 일치.
4. 학기별 학교지정 과목 + 선택군에서 고른 학점 합계의 대조 기준 일치.
5. 연간 교차 묶음이 같은 두 후보를 가지며 서로 다른 두 학기에 대응.
6. 원본 엑셀 SHA-256, 자료 범위, 미연결 과목을 audit JSON으로 기록.

표기 정규화는 공백·중간점·로마 숫자 차이만 정리한다. 학교 개설 과목을 비슷한 이름의 다른 과목과 임의로 합치지 않는다. 기존 탐색관에 연결되지 않는 학교 과목도 원래 이름과 학점으로 남기며 설명 연결 미확인을 표시한다.

출처 상태·확인일은 엑셀에 기록된 2026-10-30 기준이다. 공식 원문 PDF를 이번 구현에서 새로 대조하지 않았고, 실제 강좌 확정·학교 후속 수정·시간표를 검증하지 않았다. 학교의 최종 수강 안내를 확인해야 한다.

## 추천 계산

`assets/course-planner-engine.js`는 Node 테스트와 Worker에서 같은 함수로 실행된다. UI와 엔진을 분리했고, 계산은 `course-planner-worker.js`에서 수행해 긴 조합 탐색이 입력 화면을 붙잡지 않도록 했다.

학교지정 과목과 고정 과목을 포함하고 제외 과목은 빼며 선택군의 택N·학기 학점·전 학기 동일 과목 중복을 확인한다. 연간 교차 후보는 같은 과목을 두 번 담을 수 없어 상보적으로 배치된다. 반별 실제 배정은 미확정 순서 예시임을 표시한다.

각 선택군의 조합을 만든 뒤 전 학기를 연결하는 beam search를 사용한다. 기본 beam 48, 선택군 후보 최대 640, Worker 내부 계산 한도 약 5초다. 중간 후보마다 전체 상태를 복사하지 않고 우선순위를 비교한 뒤 남은 상태만 만들어 메모리 사용을 줄였다. 탐색 범위를 제한하므로 최적해·모든 가능 조합 발견을 보장하지 않는다. 조합이 없으면 ‘현재 탐색 범위에서 찾지 못함’으로 알린다. 계산 한도 초과 시 완성되지 않은 안을 보여 주지 않는다.

내부 우선순위는 기존 학과 안내의 관련 과목에 가중치를 주고, 균형형은 같은 선택군의 교과군 다양성도 고려한다. 내부 점수는 학업 난도·대학 적합도·합격률이 아니며 화면에 노출하지 않는다. 연계 목록에 없는 채움 과목은 ‘선택군을 채우는 대안 예시’라고 설명한다.

이수 순서 메모 중 미적분Ⅱ→대수/미적분Ⅰ, 기하→공통수학2, 미적분Ⅰ→대수는 학습 참고 경고로 처리한다. 학교의 공식 필수 선수 규정으로 강제하지 않는다. 엑셀에서 구조화되지 않은 추가 연계 규칙은 자동으로 추측해 넣지 않았다.

2027 입학생의 일반적 대입 연도는 2030으로 표시한다. 기존 탐색관의 2028 대학 권장과목 U 데이터는 추천 계산에 넣지 않았다. 이 도구의 관련 과목은 학과 학습 안내이며 2030 공식 모집요강에 따른 대학 요구로 표시하지 않는다.
