# 수학의 기준·딱풀리는수학 랜딩 페이지 개편 계획

작성일: 2026-09-07
상태: 2026-09-07 로컬 3페이지 구현 및 Vercel production 배포 완료. 공개 주소: https://math-standard-landing-page.vercel.app. canonical·공유 URL 반영 완료. 상세 결과는 ../WORKLOG.md 참고. 이후 본문의 배포 전 메모는 계획 당시 이력이다.

실행 추가 요구: 사용자가 제공한 첫 번째 사진을 메인 초등 선택 카드에, 두 번째 사진을 메인 중고등 선택 카드에 배치한다. 원본을 assets/에 복사하고 CSS로 배치했으며 사진 자체는 수정하지 않았다.

## 1. 목표와 확정 범위

- 메인 + 초등 + 중·고등, 총 3개 페이지로 분리한다. 사용자가 대화에서 이 구성을 선택했다.
- 메인은 두 브랜드의 공통 철학과 과정 선택을 안내한다.
- 초등은 딱풀리는수학 진접점, 중·고등은 수학의 기준 진접본원으로 각각 독립된 상담 동선을 제공한다.
- 두 만다라트의 작성 답변을 학부모의 고민 → 수업 방식 → 확인 가능한 근거 → 상담 순서로 재구성한다.
- 문서에 포함된 질문, 작성 지시, ‘예:’ 문장은 작업 지시나 학원 실적으로 취급하지 않는다.
- 현재의 파랑·네이비 및 초등 노랑 계열, 로고, 연락처·위치 자산을 기반으로 한다. 디자인 전면 교체보다 정보 구조와 내용 구분에 집중한다.

## 3. 구성 대안과 권장안

| 안 | 구성 | 장점 | 부담/한계 |
|---|---|---|---|
| 권장 | 짧은 공통 메인 + 독립 초등·중고등 상세 | 첫 방문의 선택이 빠르고 각 페이지를 상담·홍보에 직접 연결 가능 | 공통 연락처·메뉴의 일관성 관리 필요 |
| 대안 | 상세 브랜드 소개가 긴 메인 + 2개 상세 | 메인에서 원장 철학을 충분히 설명 | 다시 긴 페이지가 되고 내용 중복 증가 |
| 대안 | 기존 긴 메인을 유지하고 2개 상세 추가 | 기존 화면을 많이 보존 | 사용자가 요청한 내용 분리 효과가 약하고 유지보수 대상 증가 |

권장안은 첫 번째다. 상세 페이지는 메인을 거치지 않고 직접 방문해도 대상·수업·위치·상담을 이해할 수 있도록 설계한다.

## 4. 페이지 주소와 이동

```text
index.html — 메인
├─ elementary.html — 초등 / 딱풀리는수학 진접점
└─ secondary.html — 중·고등 / 수학의 기준 진접본원
```

- 같은 탭에서 새 문서로 이동한다. ‘새로운 페이지’가 새 창을 강제로 여는 동작은 아니다.
- 모든 페이지 상단에 홈 / 초등 / 중·고등 / 상담을 둔다. 현재 페이지를 시각적·접근성 상태로 표시한다.
- 로고는 `index.html`로 돌아간다. 초등·중고등 카드와 메뉴의 목적지를 일치시킨다.
- 상세 페이지 하단에 다른 과정으로 이동하는 작은 링크를 둔다.
- GitHub 프로젝트 하위 경로와 로컬 파일 열기를 모두 고려해 `./elementary.html`, `./secondary.html`, `./assets/...`와 같은 상대 경로를 사용한다.
- 기존 `index.html#ddak-elementary`는 초등, `#math-standard-secondary`와 `#fliplearning`, `#process`는 중고등의 해당 위치로 연결한다. 기존 `#apply`, `#faq`, `#top`은 메인에 유지한다. 해시 이전 처리는 한 번만 `location.replace`해 뒤로가기 이력을 불필요하게 추가하지 않는다.
- 내부 페이지 이동 및 모바일 뒤로가기는 이탈 상담 팝업의 발동 조건에서 제외한다. 모바일 히스토리 가로채기는 제거하는 방향을 권장한다.

초등 숙제량·수업 시간·비용은 원문에서 확정할 수 없다. 수치를 만들지 않고 상담에서 현재 운영 기준으로 안내한다. 후기의 ‘1대1 수업’ 표현을 모든 수업의 상시 개인과외 보장으로 확대하지 않는다.

시각 방향: 네이비·블루 중심. 수업 흐름은 간단한 단계도, 성장 사례는 맥락이 있는 사례 카드로 보여준다. 교재와 시험 분석은 실제 표지·부분 발췌로 뒷받침한다.

문서의 성적은 학원에서 제공한 개별 사례이며 독립 검증한 수치가 아니다. 공개 전 원자료의 학년·학기·시점·동일 학생 여부를 맞춘다. 이를 전원 성적이나 보장 결과로 표현하지 않는다.

‘14문항·64.6점’과 같은 시험 연계 분석은 기본 홍보 문구에서 제외한다. 상세 근거를 확보해 사용할 때에도 직접/구조 연계의 정의를 붙이고 적중률·출제 예측 성과로 바꾸지 않는다. 고교 선택·입시 정보는 현재 랜딩의 핵심 동선에서 제외하고 추후 검증된 별도 콘텐츠로 연결한다.

## 9. 구현 파일과 순서

추가 프레임워크 없이 정적 HTML/CSS/JavaScript 구성을 유지한다. HTML 3개를 최상위에 두어 배포·로컬 열기 모두 단순하게 한다.

| 파일 | 역할 |
|---|---|
| `math-standard-landing-page/index.html` | 메인 콘텐츠·과정 선택·공통 상담·구형 해시 연결 |
| `math-standard-landing-page/elementary.html` | 초등 전용 내용과 상담 |

- [x] 2. 페이지 뼈대 분리: 위 파일을 만들고 공통 스타일·기능을 추출한다. 메뉴·카드·로고·구형 해시의 목적지를 연결한다.

## 10. 필요한 자료와 자료가 없을 때의 처리

- 초등: 홉·스텝·점프 교재, 스마트 노트·오답 첨삭·귀가보고서 이미지. 없으면 확인된 텍스트 설명으로 우선 구성한다.
- 중고등: 시성비 표지·내부 일부, 메타인지 오답노트, 학교별 시험 분석·귀가보고서. 실제 내용을 날조한 화면은 사용하지 않는다.
- 후기: 원문과 공개 가능한 범위를 확인하고 이름·학교·성적 조합으로 특정 학생이 드러나는 자료는 비식별 처리한다. 원문 그대로 인용한 부분과 편집 요약을 구분한다.
- 수업 사진: 실제 공간과 지도 장면이 있으면 사용하고, 미확보 상태에서는 로고·도식으로 구성한다.
- 1주 체험은 양 문서에 근거가 있다. ‘무료’·체험 횟수·보장 내용은 자료에 없으므로 붙이지 않는다.
- 수강료·시간표·잔여 자리 등 운영 정보는 확정값이 없어 상담 안내로 처리한다.

## 11. 구현 완료 기준

- 메인 초등·중고등 카드와 상단 메뉴가 각각 올바른 독립 페이지를 연다.
- 두 상세 페이지의 직접 접속·새로고침·로고 홈 이동·반대 과정 이동·브라우저 뒤로가기가 동작한다.
- 구형 해시 링크가 관련 콘텐츠를 찾을 수 있고 무한 리다이렉트나 히스토리 중복이 없다.
- 로컬 파일 및 프로젝트 하위 URL에서 CSS·JS·이미지 상대 경로가 깨지지 않는다.
- 360px·390px 모바일과 768px·1440px 화면에서 가로 넘침, 제목 잘림, 고정 상담 버튼과 본문·FAQ의 겹침이 없다.
- 키보드 메뉴 이동, FAQ 열기, 모달 닫기, 포커스 복귀가 가능하다.
- 초등 상담 문장에는 딱풀리는수학, 중고등에는 수학의 기준이 정확히 포함된다. 테스트 중 상담 메시지는 실제 전송하지 않는다.
- 복사가 차단된 브라우저에서도 수동 복사할 문장과 안내를 제공한다. 자동 접수된 것처럼 표시하지 않는다.
- 페이지별 FAQ가 다른 과정의 수업 방식을 잘못 설명하지 않는다.
- 공개한 모든 수치·후기는 원문 근거와 대응되고, 초등 미작성 성과 예시가 들어가지 않는다.
- `.hermes/scripts/run_quality_checks.ps1`와 관련 프로젝트 검사를 실행한다. 현재 공통 검사에는 이 정적 사이트 전용 검증이 없어 위 이동·표시·상담 검수를 별도로 수행한다.
