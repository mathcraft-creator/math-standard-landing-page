## 저장 위치와 재수집

로컬 원본과 분석 결과: [`work/neis/kwangdong/2026-11-23/`](../work/neis/kwangdong/2026-11-23/)

- `school-info.json`: 학교 기본정보.
- `schulAflcoinfo.json`, `schoolMajorinfo.json`: 계열·학과 목록.
- `classInfo-연도.json`, `SchoolSchedule-연도.json`, `hisTimetable-연도.json`: 조회조건·결과 코드·총건수·원본 행.

- `timetable-content-summary.json` / `.csv`: 학년도·학기·학년·수업내용별 집계, 기록 행 수·반 수·최초/최종 날짜. **휴일·시험·창체 등도 포함하는 수업내용 집계이며, 순수 개설 과목 목록이 아니다.** CSV는 UTF-8 BOM으로 저장한 분석용 중간 데이터다.
- `capture-comparison.json`: 캡처 60행의 이름과 같은 학년·학기에서 확인된 학년도·나이스 표기명.
- `collection-summary.json`: 자료별 성공/자료 없음 상태와 건수.
- `request-manifest.json`, `metadata-request-manifest.json`: 인증키 없는 요청조건·시각·보완 조회 이력.
- `validation.json`: 총건수·학교 코드·중복·인증키 비포함 확인 결과.

```powershell
python -X utf8 scripts/collect-kwangdong-neis.py
python -X utf8 scripts/collect-kwangdong-neis.py --summarize-only
python -X utf8 -m unittest discover -s tests -p test_neis_collector.py
```

인증키는 `NEIS_API_KEY` 또는 `NEIS_KEY` 환경변수, 같은 이름의 `.env` 항목, 혹은 현재 `.env`의 단일 인증키 형식을 읽는다. 출력 폴더는 실행일(한국시간)별로 생성한다. `--summarize-only`는 실행일 폴더의 기존 자료만 읽고 API를 호출하지 않는다. 원본 수집 폴더는 Git과 정적 배포 대상에서 제외했다.

초기 조회에서 사용자 지정 HTTP 헤더와 인증키·학교명 조합에 서버 오류가 있어, 기본 HTTP 요청과 확인된 학교 코드 조회로 바꾸어 정상 수집했다. 최초 `schoolAflcoinfo` 호출은 잘못된 경로로 ERROR-310이 반환되어 그 실패 응답도 보관했다. 올바른 `schulAflcoinfo`로 보완 수집했으며 집계에는 정상 응답만 사용했다.

## 사이트 추천에 활용할 때

이번에는 자료 수집·대조만 수행했다. 기존 엑셀과 사이트의 추천 데이터는 변경하지 않았다. 나이스 시간표의 행 수는 학점이 아니며, 선택군·택N·선수과목·입학연도별 6학기 편제표가 제공되는 것도 아니다. 2027학년도 자료 없음은 학교가 과목을 개설하지 않는다는 뜻이 아니다. 광동고 2027 입학생의 완성 추천을 지원하려면 해당 입학연도의 공식 편제표·학점·선택 조건이 여전히 필요하다.

**학교 홈페이지와 나이스 공개 자료를 참고한 정보이며, 정확한 개설 과목과 운영 내용은 입학 후 학교 안내를 확인해야 한다.**

후속 요청에서 사용자가 수집 자료를 바탕으로 2027 입학생의 전체 추천을 진행하도록 지시했다. 따라서 현재 사이트는 134개 학기별 관측 후보를 활용하는 **6학기 추정 추천**을 지원한다. 위 ‘자료 수집만 수행’은 앞선 수집 단계의 기록이다. 학점·학교 선택 조건은 계속 미확인이며, 3학년은 2015 교육과정 재학생 자료 참고로 표시한다. 상세 구현은 [구현 보고서](course-planner-implementation.md)의 후속 항목을 참조한다.
