# 메인 과정 카드 CTA 강조 디자인

## 목적

메인 페이지의 초등 및 중·고등 과정 카드에서 “수업 자세히 보기”가 설명 문구처럼 묻히지 않고, 스크롤 중에도 다음 행동을 즉시 알아볼 수 있게 한다.

## 디자인

- 기존 카드 전체 링크 구조와 문구를 유지한다.
- `.course-button`을 배경색, 충분한 안쪽 여백, 둥근 모서리, 그림자가 있는 채움형 CTA로 표현한다.
- 초등 CTA는 진한 남색 배경과 흰색 글자를 사용한다.
- 중·고등 CTA는 밝은 노란색 배경과 남색 글자를 사용해 카드의 어두운 배경과 대비시킨다.
- 글자 크기와 굵기, 화살표 원의 크기를 현재보다 키운다.
- 카드 hover 또는 키보드 focus 시 CTA가 살짝 떠오르고 화살표가 오른쪽 위로 이동하게 한다.
- 키보드 사용자를 위해 카드의 `:focus-visible` 윤곽선을 명확하게 표시한다.
- 작은 화면에서는 CTA가 카드 텍스트 영역을 벗어나거나 인물 이미지와 겹치지 않도록 글자와 안쪽 여백을 조정한다.
- `prefers-reduced-motion` 환경에서는 CTA 이동 효과를 제거한다.

## 구현 범위

- `assets/site.css`의 과정 카드와 CTA 스타일만 수정한다.
- HTML 문구, 링크 목적지, 이미지, 다른 페이지의 버튼은 변경하지 않는다.

## 검증

- 데스크톱과 모바일 너비에서 두 CTA의 대비와 겹침 여부를 확인한다.
- 마우스 hover와 키보드 focus 상태를 확인한다.
- `node --test tests/*.test.cjs`, `node --check assets/site.js`, `git diff --check`를 실행한다.
